# 测试输出：入门对话模拟（示例数据）

> 虚构主人「老周」，县城 3 家社区烘焙店的老板。对话是模拟的，不进模板。

**墨灵：** 你好，我是墨灵，灵境里管长文的那位。我陪你把亲手干过的事写成别人愿意收藏的长文，再改成每个平台的版本。接下来问你几个小问题，一次一个，随时可以跳过。先问第一个：我该怎么称呼你？

**主人：** 叫我老周。

**墨灵：** 好，老周。你靠什么吃饭？老板、操盘手、自由职业，还是别的？

**主人：** 开了 3 家烘焙店。

**墨灵：** 3 家店，那你手里肯定有不少真事。你最想让谁读到你的文章？我推荐「准备开店、比你晚几年入行的人」。也可以选同行、潜在客户或者老板。

**主人：** 就是想开店的人。

**墨灵：** 明白。说 1 到 3 件你亲手干成，或者亲手踩过坑的事，带上数字最好。

**主人：** 第一年亏了八万多；门口坐三天数人头选址，第二家店三个月回本；下午四点后半价，报废从四十多个降到七八个。

**墨灵：** 三件都带数字，够写好几篇了。要发哪些平台？默认是 X、公众号、抖音长文、知乎、微博五个都发。

**主人：** 公众号和抖音就行。

**墨灵：** 好。还要不要加别的平台？比如小红书很适合做开店的笔记。也可以暂时不加。

**主人：** 加小红书。

**墨灵：** 记下了，小红书的规格我写第一篇前会先查一遍。接下来请发我 3 到 10 段你自己写的东西，朋友圈、口播稿都行。
*（主人发了 3 段，墨灵调用 voice-profile，生成的档案见 ../voice-profile/test-output-口吻档案示例.md，确认后回来）*

**墨灵：** 口吻档案定好了。哪些内容不能写？默认不写收入数字、客户名字、家人、所在城市。

**主人：** 亏钱、回本的数可以写，城市不写。

**墨灵：** 好，城市不写，亏损和回本的数字可以用。……（第 8～10 题略：文末福利选「帮我设计」，入口关键词不用，视觉用默认，雷达和复盘先不开）

**作者档案（墨灵写入记忆并发给主人确认）**
```
作者档案（最后更新：2026-10-20）
称呼：老周
身份 / 行业：县城 3 家社区烘焙店老板
写给谁 / 他们愁什么：想开店的人｜怕选错址、怕亏钱
真事素材库：
  1. 第一年亏损｜八万多｜房租 6000/月、选址只看人流｜可公开
  2. 门口数人头选址｜3 天｜第二家店 3 个月回本｜可公开
  3. 下午四点后半价｜报废 40+ → 7～8 个/天｜可公开
平台：公众号、抖音长文，新增小红书（规格待查）
禁写：所在城市
文末福利：待设计
入口关键词：无
视觉：默认（粗体大字 + 一个主色）
日常任务：雷达 关｜复盘 关
还没问的题：无
```

**第一批选题**
1. 「开了 11 年烘焙店，我第一年亏了 8 万多，全亏在选址」｜读者正好怕这件事｜收藏件：选址自查表
2. 「在门口坐 3 天数人头，我的第二家店 3 个月回本」｜方法土、能照做｜收藏件：数人头记录模板
3. 「每天扔 40 多个面包，一个改动降到 7 个」｜新手都会遇到，而且给了数字｜收藏件：报废成本计算表

**墨灵：** 先写哪一篇？

---
**测试结论：** 一次一问、选项加推荐、跳过用默认、第 6 题转交口吻学习、档案确认、出选题，这几个环节都跑通了。发现一处要补：主人只选了部分平台时，第 4 步的标题要按他选的平台出字数缩写版。这件事由选题与标题技能负责，写技能③时要记得加上。
