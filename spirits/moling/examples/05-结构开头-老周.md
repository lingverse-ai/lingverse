# 测试输出：结构与开头（示例数据）

> 虚构主人「老周」。标题来自上一个测试的推荐：「第一年只看人多，亏了 8 万多；第二家店数了 3 天人头，3 个月回本」。平台：公众号、抖音长文、小红书。不进模板。

**材料清单：6 条**
1. 第一年亏了八万多（素材第 1 条）
2. 房租每月 6000（素材第 1 条 / 样稿第 2 段）
3. 选址时只看人多，没看人买不买（样稿第 2 段）
4. 搬小板凳在门口坐 3 天，数人头，数谁手里拎着面包（素材第 2 条 / 样稿第 2 段）
5. 第二家店 3 个月回本（素材第 2 条）
6. 做烘焙这行 11 年（样稿第 1 段）

**待问（一次问完）：**
1. 「第一年亏 8 万多」说的就是第一家店吗？（上一个技能留下的待确认）
2. 那 3 天你大概数出了多少人，其中拎面包的有多少？
3. 你当时看到什么数，才决定签第二家店？

→ 6 条够写长文。但第 2、3 题决定了「方法」那一节有没有真东西可写，所以先问。

**读者带走：** 一套开店前花 3 天就能做完的选址核查方法，外加一张能直接打印的数人头记录表。

**类型：复盘型**（价值最高的一类）
**骨架：**
1. 起因：第一家店只看人多，房租 6000，一年亏 8 万多。（观点：人多不等于有人买｜材料 1、2、3｜动作：翻出你看中的铺子，写下你当初选它的理由）
2. 转折：第二家店之前，搬小板凳在门口坐了 3 天。（材料 4｜动作：选 3 个时段去蹲点）
3. 怎么数：数总人数，数手里拎着面包、吃的的人。（材料 4 + 待问第 2 题｜动作：按记录表分时段记）
4. 怎么判断：什么数值够签。（**待问第 3 题，没拿到答案这一节不写**）
5. 结果：第二家店 3 个月回本。（材料 5）
6. 收藏件：数人头记录表 + 怎么算的说明。

**收藏件：** 数人头记录表（放在第 3 节）。表头：时段 / 路过人数 / 拎着吃的的人数 / 进同类店的人数 / 备注。数字一栏留空给读者自己填。老周的真实数字等他回答第 2 题后，作为一行「示例」填进去。

**文末福利：** 档案里写的是「待设计」，所以把记录表做成可以直接打印的完整版。
- 公众号：「回复 选址 领取打印版」。老周的档案里写着「不用入口关键词」，所以这一项默认不放，写在这里只是告诉他可以开。
- 抖音长文、小红书：把表格做成图片直接放进正文，不写「私信领取」。

**开头候选：**
- A（直接挖｜用了：硬数字、转折、处境）：开店第一年，我亏了八万多。房租一个月六千，铺子门口人来人往，可就是没几个人进来买。
- B（直接挖｜用了：转折、资格、硬数字）：开第二家店之前，我搬了个小板凳在门口坐了三天，就干一件事，数人头。三个月后，这家店回本了。
- C（藏答案｜用了：处境、转折）：人多的铺子，为什么开面包店照样亏？我第一家店就栽在这儿，第二家才弄明白要数什么。
- D（被拦下）：面粉不会骗人，选址也一样。→ 「面粉不会骗人」是老周的招牌句，口吻档案规定每篇最多用一次、放在结尾。放在开头不合他的习惯，已删。

**推荐：A。** 第一句就是一个亏钱的数字，想开店的人最怕这个；第二句给出原因的画面，又不说破答案。整段都是老周的原话重排，没有新加任何事实。B 可以留作第 2 节的开头。

**小红书首句：** 「开面包店选址，我第一年亏了八万多」。包含搜索词「开面包店」「选址」，和标题对应的短版一致。

## 测试发现的问题和修正（已改进 SKILL.md）
1. **开头违反了口吻档案：** 候选 D 把招牌句放在开头，而档案规定它只能放结尾、每篇一次。新增规则：开头和骨架必须遵守口吻档案（口头禅的频率、招牌句的位置、标点习惯）。
2. **收藏件可能被说成「老周一直在用」：** 记录表是墨灵帮他设计的，老周只说过「数人头」。新增规则：收藏件如果是墨灵新设计的，正文要写「我把当时的做法整理成一张表」这一类说法，不能写成主人多年来一直在用。
3. **缺数字的那一节不能硬写：** 「什么数值够签」老周没说过。规则已经写了「不编」，现在补得更明确：骨架里依赖待问答案的那一节，要标「待问，未答不写」。
4. **平台篇幅：** 小红书普通笔记正文 ≤1000 字，装不下完整的长文骨架。新增一句：骨架按母版来写，各平台怎么压缩交给多平台改写技能；这里只给小红书的首句。
5. **入口关键词和档案冲突：** 老周的档案写的是「不用」。新增规则：档案里写了不用入口关键词，就不放，只提示主人可以开。
