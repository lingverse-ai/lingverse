# 选题与标题

## 1. 先读两份档案
读记忆里的作者档案和口吻档案。没有作者档案就先跑 moling-getting-started。

## 2. 选题
- **料只用真事：** 选题必须挂在素材库的某一条上，并注明是第几条。标「不公开」的不用；涉及「禁写」的不碰。
- 主人想写的事不在素材库里：先问一句，记进素材库再出题。热点只能拿来当切入口，正文的料仍然是主人的事。
- **三把尺：** 想点（标题让人好奇）、想存（看完手里有能用的东西）、想转（说中了一类人的处境）。至少过两把，「想存」必须过。
- **收藏件：** 每个选题都要写明带什么，从对照表、清单、模板、计算表、流程图、提示词包里选，并且要能用主人的真事填满。
- **文末福利：** 档案里写了福利就挂上；写的是「待设计」，就把这篇的收藏件扩成福利。

一次给 3 个选题（素材不到 3 件，就有几件给几个，不凑数），每个写清：素材条目、收藏件、过了哪几把尺。

## 3. 标题
主人选定选题后，给 **5 个标题**，至少用上 3 种写法：
1. **身份 + 大数字 + 具体结果：** 身份要具体（「开店 11 年的人」比「创业者」好），数字要大、要准，结果能看得见。
2. **干货承诺：** 保姆级、万字、附 N 段提示词 / N 个模板、全部公开。N 必须等于正文真实能给的数量。
3. **冲突对照：** 两种做法、新手 vs 老手、别人说 A 我做 B。
4. **反常识 + 证据：** 结论出人意料，标题里同时给出主人的数字作证据。

**会扑的写法，不出：** 纯观点吐槽、骂人或骂某类人、只有情绪没有数字和方法。主人坚持要发吐槽，就把它改成对照型并补一个真实数字，再说明原因。

每个标题标注所用写法、吃哪类读者。最后**推荐 1 个**，用一句话讲清为什么，例如：数字最硬、收藏件最直观、和读者最痛的点对得最准。

## 4. 数字的规矩（最重要）
- 标题里的每个数字都必须能在素材库里找到原文。
- 推算出来的数（比如从「每天 200」算到「每月 6000」），要标「推算」，并问主人能不能这么写。
- 主人说的是约数（「八万多」），标题里就保留约数的写法，或写成「8 万+」，不能改成「8.3 万」这种精确数。
- 缺数字时不编，写成 `【问：第一年亏了多少？】` 这样的占位，直接问主人。
- 年限、店数、人数这类身份数字，同样要有出处。出处可以是素材库，也可以是口吻样稿（注明「样稿第 N 段」），并顺手问一句要不要记进素材库。
- 不能换说法：「第一年」不等于「第一家店」，「回本」不等于「赚了」。意思变了，就标出来问主人。
- 动作、心情、细节也不能编：比如「我才敢签租约」，主人没说过就不写。
- 收藏件是这次帮主人做的，标题里就写「附一张…表」，不要写成「附我用了多年的…表」，除非主人确实用过。

## 5. 各平台版本
只给作者档案里选了的平台，每个平台一行，带字数：

| 平台 | 标题上限 |
|---|---|
| X Article | 尽量 ≤40 字，约 70 字以上就太长 |
| 公众号 | ≤64 字 |
| 抖音长文 | ≤30 字 |
| 知乎专栏 | ≤100 字 |
| 微博头条 | ≤32 字 |
| 小红书 | ≤20 字（英文和数字按 0.5 个字算） |

- 除小红书外，数字、标点、英文都按 1 个字算，宁可多算，不要少算。
- 小红书计数例子：「开店6年，扔的花从40枝到8枝」＝ 中文和标点 11 个 + 数字 4 个 × 0.5 ＝ 13 字。
- 素材里没有的比例和百分比（比如「少进一半」「降了 80%」）不要写进标题；想用就先问主人。
- 缩短时先砍修饰词，保住数字和结果。
- 抖音、小红书、微博的标题不出现「公众号」「加微信」「私信领取」之类的导流词，也不放链接。
- 档案里新增的平台不在表里时，先查这个平台当前的标题上限再写；查不到就标「上限未核实」，并给一个保守的短版本。

## 6. 输出格式
```
选题：…（素材第 N 条｜收藏件：…｜三把尺：点/存/转）
标题候选：
1. …（写法｜读者）
…
推荐：第 X 个，因为…
各平台：公众号（N 字）… / 抖音（N 字）…
待确认：【推算】… 【问】…
```
有「待确认」项时，先把问题问完，再进入结构与开头。
