# 配图与封面

尺寸以 moling-multi-platform 技能目录里的 `platforms.md` 为准；读不到，就用下面的速查表，并提醒主人规格可能不是最新的。

## 尺寸速查
| 平台 | 封面 | 正文配图 | 要注意 |
|---|---|---|---|
| X Article | 5:2 | 16:9 或原图比例 | 两侧会被裁，字放中间 |
| 公众号 | 2.35:1，同图再裁 1:1 | 宽图 | 1:1 那张也要看得清标题 |
| 抖音长文 | **3:4 竖版**（强制） | 3:4 | **底部约 1/5 会被标题和文案盖住**，不放字 |
| 小红书 | 3:4（1080×1440），也可 1:1 | 3:4，最多一组 | 封面就是第一张图，决定点不点 |
| 知乎专栏 | 16:9（1920×1080） | 宽图 | 信息流会裁中间 3:2 到 2:1 的区域，重点放中间 |
| 微博头条 | 16:9（≥1000×562） | 宽图 | 可以和知乎共用一张 |

## 1. 封面的字
- **只用粗重字重**：黑体或圆体，选 Bold / Heavy / Black。不用细体、宋体细字重、书法体或花体。
- **字要大**：在手机信息流的缩略图里也能一眼读清。主标题最多两行，每行最好不超过 8 个字。
- 封面上的字，从平台标题里挑最狠的那半句，通常是数字加结果，比如「扔四十多个 → 七八个」。不用把整个标题搬上去。
- 一张图里最多两种字号、两种主色。字和底色对比要强。
- 封面上的数字和事实，必须和正文一字不差；约数照写原话。

## 2. 安全区
- 抖音：底部约 1/5 不放字，也不放重要内容。
- 小红书：底部约 15%～20% 可能被界面盖住，标题、人脸、产品放在中间偏上。
- 知乎、X：会被裁边，关键内容放在中间 3:2 的区域。
- 公众号：做完 2.35:1 后检查裁成 1:1 的效果，主标题要完整在里面。

## 3. 禁导流平台的图（抖音、小红书、微博，以及知乎的导流部分）
图里**不放**二维码、网址、短链、微信号、公众号名、「私信领取」、水印里的账号。
**价格不出现在图里**（比如可以写「便宜卖」，但「10 元一把」不能进图）：「原价 / 现价 / 到手价」这类字眼都不放。主人确实要讲价格，就写在正文里，并且要有依据。
平台截图和别人的作品截图，先把对方的头像、账号、联系方式打码。

## 4. 收藏件做成图
- 表格、清单、流程、提示词合集：做成一张能截图保存的图，每张只讲一件事。
- 竖版平台用 3:4；宽版平台用 16:9 或长图。竖版放不下超过 4 列的表，就改成每行一张卡片，或者拆成两张图。
- 图上的字号比正文大一号，行距松一点。表头写清楚这张表是干什么用的。
- 墨灵设计的表要写成「我把做法整理成了表」，不要写成主人一直在用这张表（除非主人确认过）。

## 5. 真实照片
- 优先用主人自己拍的照片：店、产品、现场、手写记录，比生成图更可信。
- 尺寸不对时**缩小放进画布，四周补底色或模糊背景**，不要硬裁掉人脸、产品或关键信息。只有裁完主体还完整时才裁。
- 不修改照片里的事实，比如数字、招牌、价格签。
- 照片里有顾客或员工的脸，先问主人有没有授权；没有就打码。

## 6. 出图
- 主人的 bot 有出图能力，就直接出：每张图先说用途和尺寸，出完让主人挑。
- 没有出图能力，就给提示词：画面、构图、比例、字（原文照写）、字体字重、颜色、安全区要求。
- 生成图不冒充实拍，比如不生成「我的店」「我的产品」去冒充真的。要用就标为示意图。
- 生成图里有文字时逐字核对；出现错字或乱码就重出，或者改成后期用粗重字体加字。

## 7. 输出（每个平台一块）
```
【平台】封面 尺寸｜字：…（字体字重）｜安全区：…
配图：图1 用途 / 尺寸 / 来源（实拍 / 生成 / 表格）
收藏件图：…
清扫：二维码 / 网址 / 价格 / 账号，N 处
提示词或图片：…
```
