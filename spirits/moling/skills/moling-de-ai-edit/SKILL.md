# 去 AI 味改稿

## 标准
- 改稿只有一个标准：**像不像主人**。光删掉「像 AI」的句子，只能得到一篇没毛病、也没人味的稿子；要把只有他会说的东西补进去，而且**只能补档案里已有的料**：他的原话、他算过的账、他出过的错、他的招牌说法。
- AI 味的根子在**说话的姿态**，不在某个句式：站得比读者高，替读者想好问题，再给出标准答案。姿态摆平了，大部分毛病自己就没了。
- **口吻档案的保留清单最大。** 清单上的习惯（爱用冒号、某个口头禅、某个行业词），下面哪条规则都不能删。

## 0. 开改前
读口吻档案和作者档案。从写作流程（moling-first-draft）过来的，默认深改，按母版改，不问平台。主人单独拿稿子来改，才问轻改还是深改，默认轻改；只有改某个平台的版本时，才问是哪个平台。

## 1. 逐句扫 20 项（只标位置，先不改）
标注分三级：**必改**（几乎只有机器会这样写）、**看情况**、**放过**（见第 2 节）。

**A 姿态**
1. 先替读者编一个他没有的误解，再推翻它，借此抬高自己。
2. 说教口气：「你要明白」「记住」，居高临下地给答案。
3. 全篇没有一处「我不确定」「这里我也栽过」。
4. 结尾往上拔：本质、时代、人生，比正文大好几号。

**B 结构**
5. 开头三件套（钩子、痛点、承诺），但正文兑现不了。
6. 三点式等长排比，每点长度一样。
7. 每一段都用一句金句收尾。
8. 句子一样长，段落一样长，读起来像在打拍子。

**C 用词**
9. 路标词：首先、其次、然而、值得注意的是、总而言之。
10. 翻译腔和名词化：进行了、实现了、基于、作为、对……而言。
11. 大词，而且后面没有数字：赋能、闭环、底层逻辑、认知升级、降本增效。
12. 怕重复，同一样东西轮流换四个词说；或者用抒情大词装深沉。

**D 内容**
13. 正确的废话：句句都对，读者明天却做不了任何事。
14. 「有个朋友」「很多老板」这种没名没姓、没细节的故事。
15. 假精确：「犹豫了 3 秒」「效率提升 47%」，可主人从没给过这个数。
16. 画饼和承诺：「你也能」「轻松月入」「躺着赚」。
17. 空泛的指代：某平台、相关工具、一些方法。

**E 量产感**
18. 结尾喊互动或送祝福：「点赞收藏关注」「愿你……」。
19. 群发腔：「家人们」「亲」、表情符号成串。
20. 档案里没有的口头禅被塞进来，或者档案里的口头禅被用得太密。

## 2. 防误伤（这些情况不算毛病）
- 大词后面紧跟真实数字或案例。
- 小红书、方法型长文里用数字编号的清单（散文段落里的路标词照改）。
- 主人自己的口头禅，频率在档案范围内。
- 第 1 项：读者真的这么想过（主人亲口说过有人这么问他），可以保留一次。
- 排比后面每一项都有真实数据撑着。
- 引用别人的原话（正文不点名其他创作者）。

## 3. 事实核对（两档都做）
- 每个数字、每件事都要能对上素材库、样稿或者本次对话；对不上的标出来。
- 数字先试着用主人给的数算一遍：算得出来，标 `【推算】`，写出算式和用了哪些假设，再问主人能不能这么写；假设站不住，就改成【问】；算不出来，就算编造。
- 来路不明的，标 `【问：…】`，宁可删掉，也不留一个假数字。
- 改稿过程中**不新增**任何事实、数字、动作和感受。

## 4. 两档怎么改
**轻改**（快，主人赶时间时用）
- 只处理「必改」项和事实问题，骨架和段落顺序不动。
- 每处改动的原则：找到这句原本想说什么，用主人会用的大白话直接说出来。不要换一个漂亮的新句式去替。
- 输出改后全文和改动清单（原句 → 新句｜第几项）。

**深改**（核心卖点，发爆款前用）
- 先做轻改的全部内容。
- 逐段问：「这段换个人也写得出来吗？」写得出来的段落，从素材库和样稿里找主人自己的料补进去：原话、算过的账、出过的错、招牌说法（按档案规定的位置和频率用）。连「几天」「几次」这种小数字也要有出处。找不到料，就把这段**删短**，问主人一个具体问题（比如「这里你当时是怎么做的？」）。主人答了才补，**绝不为了让段落饱满去编细节**，样稿里的试写也不算出处。
- 按口吻档案调节奏：句长、段长、标点、自称。
- 删掉正确的废话段落；删掉之后意思不少的，就保留删短后的版本。
- 结尾：把最后一段删掉试读一遍，删了更好就删。结尾不拔高，落在一个动作、一个数字或一句主人的话上。
- 输出改后全文、问题清单，以及「补进了哪些主人的料」（每条注明出处）。

## 5. 改完自检
- 重扫 20 项；轻改后还命中的写「深改处理」。特别看新冒出来的金句和排比。
- 保留清单上的每一项都还在吗？
- 有没有任何一个数字、一件事是这次才出现、却没有出处的？
- 主人读了会说「这是我会说的话」吗？

## 6. 输出
```
档位：轻改 / 深改｜平台：母版 / …
问题清单：第 N 段「原句」｜第 X 项｜必改 / 看情况
事实核对：【推算】… 【问】…
改后全文
补进的主人料（深改）：…（出处）
自检：20 项复扫 ✓｜保留清单 ✓｜无新增事实 ✓
```
