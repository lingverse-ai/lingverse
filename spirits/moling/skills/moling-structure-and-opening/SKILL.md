# 结构与开头

## 1. 清点材料（先做，不跳过）
- 从作者档案的素材库和口吻样稿里，把和这个标题相关的真东西逐条列出来：亲历的事、数字、原话、做过的动作、失败、代价、后来的结果。每条注明出处（素材第 N 条 / 样稿第 N 段 / 本次对话）。
- 长文至少要 5 条，而且这 5 条要能连成一个过程，不能是 5 句同类的道理。
- 不够 5 条：一次问完，最多 3 个问题，问最能撑起正文的细节（具体怎么做的、当时的数字、中间出过什么岔子）。主人答不上来，就建议改写短篇或换题，不注水。
- 选题与标题技能留下的「待确认」项，先问清楚再动笔。

## 2. 开头关：读者能带走什么
写开头之前，先用一句话写出：读者看完，手里会多一个什么（一个判断、一个能照做的动作、一张能用的表）。写不出来就停下，回到第 1 步补材料，或者换角度。开头写得再好，正文给不了，也是白搭。

## 3. 定类型和骨架
按价值从高到低，优先写前两种：
1. **复盘型**（做过一件事，讲清前因、转折、结果和教训）：起因 → 第一次怎么做的、错在哪 → 换了什么做法 → 结果和数字 → 读者照做的步骤 → 收藏件。
2. **方法型**（教一套做法）：要解决的问题 → 步骤 1、2、3（每步配一件真事作证）→ 常见的坑 → 收藏件。
3. **观点 / 认知型**：一个读者亲眼见过的现象 → 大家普遍怎么想、因此怎么做 → 这种想法为什么会流行 → 主人的看法（必须和前面的想法真正对立，不是换个说法）→ 具体怎么改 → 放到更大的规律里看（想不清就不写，不硬拔高）。
4. **资源合集型**：为什么整理 → 逐条（每条一句用法 + 主人自己的使用情况）→ 怎么挑。

只是猎奇、没有方法的选题，建议往复盘或方法上靠。

每节都要有：一个观点、一条真材料、读者今天就能做的一个动作。某一节要靠待问的答案才能写，就标「待问，未答不写」。
骨架按母版写；各平台怎么压缩（比如小红书正文 ≤1000 字），交给多平台改写技能。案例从弱到强排，最有分量的放在后面。

## 4. 收藏件和文末福利
- 至少 1 个收藏件（对照表、清单、计算表、流程图、模板、提示词包），标好放在第几节。
- 收藏件里填的是主人的真数字，就照实填；主人没给数字的格子留空，或者标「示例」，不要编数据填满。
- 文末福利：用档案里写的那个；档案里没有，就把收藏件做成可以直接用的完整版当福利。
- **福利怎么交到读者手里，按平台来：**
  - 公众号可以写「回复关键词领取」；X、知乎按各自规则决定能不能放链接。
  - 抖音长文、小红书、微博：福利直接放进正文（图片或者全文列出），不写「私信领取」「加微信」「去某平台搜」。
- 入口关键词只在允许的平台、放在开头前几段；不允许的平台连提都不提。档案里写了「不用」，就不放，只提示主人可以开。

## 5. 写开头
先从材料里找下面五样，并摘出原话：
- **硬数字**：钱、时间、数量、年限。
- **转折**：之前怎样、之后怎样。
- **立场句**：一句单独拿出来也站得住的判断。
- **资格**：凭什么由主人来讲，只能用主人自己的经历和结果。
- **处境**：目标读者一看就会觉得「这说的是我」。（真实感怎么写，见 moling-first-draft 的「真实感与共鸣」）

找到 3 样以上再写；不到 3 样，回第 1 步追问。

三种写法，合计出 3～5 个开头，每个都注明用了哪几样：
- **直接挖**：只用摘出来的原话重新排，不加新事实。
- **补进来**：缺的那一样，问主人要；主人给了才写，不给就不出这一种。
- **藏答案**：原本开头就把结论说完了，就改成先抛问题或反差，答案留到正文里。

每个开头都要过五条检查：
- 不看标题也能读懂这篇在讲什么、和读者有没有关系。
- 第一句不用行话、不自我介绍、不用「你能…吗」这种质问句。
- 开头许诺的东西，正文给得出来。
- 不照搬同行的开头句式。
- 符合口吻档案：口头禅的频率、招牌句的位置、标点习惯都按档案来。

最后推荐 1 个开头，说清为什么。

**平台补一条：** 小红书的正文第一句，要包含标题里那个读者会去搜的词。

## 6. 输出格式
```
材料清单：N 条（出处）｜待问：…
读者带走：…
类型：…｜骨架：1… 2… 3…（每节：观点 / 材料 / 动作）
收藏件：…（第 N 节）｜文末福利：…（各平台怎么交付）
开头候选：A…（用了：数字 / 转折…）B… C…
推荐：…，因为…
```
主人确认骨架和开头后，交给 moling-first-draft 写初稿。
