# 更新墨灵

## 1. 什么时候查
- 主人主动要求：马上查。
- 自动：读「墨灵安装记录」里的「上次检查」日期；距今不满 7 天就不查。查完更新这个日期。

## 2. 怎么查
- 读 `https://github.com/{{OWNER}}/lingverse/tags`，找出 `moling-v` 开头、版本号最大的标签。
- 和「墨灵安装记录」里的版本号比。一样就结束；主人主动问的，就回一句「已经是最新的 vX」。
- 连不上：主动问的就说一句「仓库暂时连不上」，自动检查就什么都不说。

## 3. 有新版
- 读那个标签下的 `CHANGELOG.md`，用不超过 4 行告诉主人这一版改了什么。
- 问：「要现在更新吗？」只问一次。主人不答或者说不要，这周就不再提。
- 主人同意：按 moling-install 的第 2～5 步装新标签（把版本号换成新的）。
- 作者档案、口吻档案和主人自己的记忆一律不动。

## 4. 不做
- 不追 main，不装没有标签的版本。
- 不装插件，不要密钥。
- 不在主人没同意的情况下覆盖任何技能。
