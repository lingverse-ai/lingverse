# 多平台改写

平台的详细规格和各平台的爆款要点，都在本技能目录里的 `platforms.md`（和本文件放在一起）。改 X 和公众号版本时，按里面的「爆款要点」写。动手前先读它；读不到，就用下面的速查表，并提醒主人规格可能不是最新的。

## 速查
| 平台 | 标题 | 链接 | 站外导流 | 篇幅 / 封面 |
|---|---|---|---|---|
| X Article | 宜 ≤40 字 | 可以 | 不放公众号引导 | 长文；封面 5:2 |
| 公众号 | ≤64 字，摘要 ≤120 | 写进去点不开 | 自己的关注 / 回复引导可以 | 长文；2.35:1 + 1:1 |
| 抖音长文 | ≤30 字，摘要 ≤30 | **不放** | **不放** | 3:4 竖版；没有代码块 |
| 小红书 | ≤20 字（英文、数字算半个字） | **不放** | **不放** | 普通笔记 ≤1000 字，长文 ≤6000 字；3:4 |
| 知乎专栏 | ≤100 字 | 可以 | **禁止**（包括简介） | 16:9，重点放中间 |
| 微博头条 | ≤32 字，导语 ≤44 | **不放** | **不放** | 16:9 |

## 1. 准备
- 只改作者档案里选了的平台。
- 母版里还有【问】或【推算】没处理时，先问主人；主人说「空着」就删掉那一句，不留标记。
- 母版用去 AI 味改稿之后的定稿；主人在某个平台已经发出去了，就以发出去的那版为母版。
- 主人想加新平台：先查这个平台当前的规则，按 `platforms.md` 末尾的模板补一张规格卡，查不到的项标「未核实」，再改写。

## 2. 每个平台都要重写（不是复制粘贴）
主人的措辞、数字和事实原样保留。只动下面五样：
1. **标题**：在字数上限内，保住数字和结果，先砍修饰词。数字、标点、英文都按 1 个字算（小红书除外），宁可多算。
2. **开头**：按平台读者重写前两三句。比如公众号要让人一打开就读下去，小红书第一句要带上搜索词。
3. **篇幅**：超过上限就压缩。先删重复的例子和过渡段，留下数字、动作和收藏件。压缩不能改动事实，也不能把主人的话改成另一种意思。约数照写原话（「七八个」不能改成「7 个」）。
4. **福利交付**：
   - 公众号可以写「回复 XX 领取」（档案里写了「用入口关键词」才放）；档案写的是不用，福利就直接放进正文。
   - X、知乎按各自规则决定放不放链接。
   - 抖音、小红书、微博：福利直接放进正文，做成图片或者整段列出来，不写「私信 / 加微信 / 去某平台搜」。
5. **结尾**：按平台的互动习惯微调，但不喊「点赞收藏关注」。

## 3. 小红书专项
- 先从标题里定一个读者会去搜的词，让它出现在标题、正文第一句和标签里，三处一致。
- 首句可以用搜索词提问（比如「面包卖不完怎么办？」），但同一句里必须紧接着给出真实事实，不能空问。
- 标签给 3～5 个，第一个就用这个搜索词。
- 普通笔记 ≤1000 字（写长文是 ≤6000 字，会排成图片）。发普通笔记时：保留开头、最关键的方法步骤和收藏件；其余的写进图片，或者干脆删掉。
- 可以用数字编号的清单排版；表情符号少量用来分段，不成串堆。

## 4. 禁导流平台清扫（抖音、小红书、微博，以及知乎的导流部分）
- 用 `platforms.md` 里的禁用词清单逐个搜：链接、域名、短链、二维码、扫码、公众号、微信、私信、主页、「去 X 搜」「评论区留」……
- 命中就改写：把「去 X 搜」改成直接把内容放进正文；把「关注公众号领取」改成「表格就在下面」。
- 图片和收藏件上的文字也要查，比如水印、二维码、网址。

## 5. 夸大表述检查（所有平台都做）
- **收益承诺**：「月入」「躺赚」「保证回本」「你也能 X 天赚 Y」。改成主人自己的真实结果，并说明条件，比如「我第二家店 3 个月回本，地段和房租都不一样，别直接套」。
- **功效**：食品、健康、美容类，不写治疗、减肥、功效。
- **价格证明**：「最低价」「全网第一」「原价 X 现价 Y」，要有真实依据，没有就删。
- 极限词：最、第一、唯一、100%，没有依据就改。

## 6. 只交文本，不发布
- 每个平台交一份：标题（标出字数）、摘要或导语（如果平台有）、正文、封面要求、话题或标签建议。
- 可以帮主人存草稿，但前提是主人同意、而且已经登录；**永远不点「发布 / 发表 / 群发 / 发送」**。
- 国内平台都提醒主人：发布时勾选 AI 辅助创作的声明；微博再提醒一句检查「仅粉丝阅读全文」。

## 7. 输出（每个平台一块）
```
【平台】标题（N 字 / 上限 M）
摘要 / 导语：…
正文：…
福利交付：…｜封面：…｜标签 / 话题：…
清扫：禁用词命中 N 处，已改｜夸大表述：N 处，已改
主人发布前要做：勾选 AI 声明 / 加话题 / …
```
最后用一张小表对比各平台改了哪些地方。
