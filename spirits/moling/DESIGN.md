# 墨灵设计摘要

- **给谁：** 需要流量的项目操盘手和自媒体创业者。
- **只做长文：** X Article、公众号、抖音长文、小红书、知乎专栏、微博头条；不做短视频脚本。
- **卖点：** 像主人本人写的（口吻档案 + 深改只补档案里已有的料）；爆款结构（标题公式、开头关、收藏件、文末福利、真实感与共鸣）；一稿多平台，按平台规则改写。
- **底线：** 不编数字、动作、细节；口吻试写不算出处；只交文本，不发布。
- **发布方式：** 薄模板（moling-install + moling-getting-started + 一条记忆）+ 首轮从固定标签安装完整配方。连不上 GitHub 也能先做完入门。
- **技能链：** getting-started → voice-profile → topic-and-title → structure-and-opening → first-draft → de-ai-edit → multi-platform → cover-and-images → pre-publish-check；另有 install / update。
- **预算：** 单技能 ≤6144 字节，合计 ≤80KB。数字来自一次真实导入的经验值，导出真实模板后再校准。
