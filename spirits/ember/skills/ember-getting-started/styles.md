# 风格预设库（入门时让主人选，默认 = v11 同款）

每个预设都给齐：配色、服装、场景库、Suno Style、剪辑节奏与字效、调色 LUT（`/workspace/ember/luts/<名>.cube`）。
预设只是起点：选完后每一项都能在选项里改。**所有预设都不放真实品牌 logo**，服装一律写 no logo。
